# Test-Plans/

Two kinds of notes live here, both tagged with `type` in their frontmatter so they're easy to tell apart at a glance:

- `type: test-plan` — an ATP outline from a shift-left review: what's planned to be tested and any open questions.
- `type: test-case` — one specific case, with an ROI verdict (`verdict: candidate | manual | deferred`) deciding whether it's worth automating.

Filed automatically by `/shift-left-testing`, `/sprint-testing`, and `/test-documentation` — see `.claude/skills/qa-obsidian-notes/SKILL.md` for the exact conventions.
