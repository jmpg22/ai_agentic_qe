# Bugs/

One note per confirmed issue (`type: bug`), each with steps to reproduce, expected vs. actual behavior, environment, evidence, and severity — see `.claude/skills/agentic-qa-core/references/defect-notes-doctrine.md` for the exact required fields. Filed by `/sprint-testing` and `/regression-testing` whenever something turns out to be a real application problem (not a bad test).

`status` in each note's frontmatter tracks its life: `open -> triaged -> fixed` (or `wontfix`).
